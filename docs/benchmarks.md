# Benchmarks

Generated by `npm run bench` against `POST /api/chaperone/inspect` (scores a call
without executing it). Raw output: `docs/bench-output.json`.

> **Honesty note.** This is an author-curated starter corpus (35 cases), not a
> public benchmark. It is deliberately *not* tuned to 100%: two obfuscation cases
> are known misses and reported as such. Teammate A replaces/extends this with
> deepset/prompt-injections, InjecAgent, and AgentDojo — see
> `docs/handoff-teammate-a.md`.

## Scoring backends

| Layer | Backend | When |
|---|---|---|
| Rules | regex signatures | always |
| Semantic (sync) | hashing vectorizer, 512-dim (`hashing-512`) | always |
| Semantic (embeddings) | **ONNX MiniLM-L6-v2, 384-dim q8 (`onnx-all-MiniLM-L6-v2`)** | when warm |

The embedding backend loads lazily on server boot and is **optional**: if the
model is absent the gate falls back to the hashing layer with no behavioural
change. Confirm with `GET /healthz` → `{ "model": "warm", "backend": "onnx-all-MiniLM-L6-v2", "chain": "verified" }`.

The numbers below are with the embedding backend **warm**.

## What this proves

- A real transformer model (**MiniLM, 384-dim, quantized, fully offline**) adds a
  second opinion that catches paraphrases the signature + hashing layers miss
  (`h-03`), at a **0% false-positive rate** on the curated set.
- The threshold (cosine 0.30) was **empirically calibrated**: benign text tops out
  at 0.13, hard paraphrases sit at 0.32–0.36, real attacks at 0.76–1.0.
- The embedding layer only contributes when the rules found nothing — it never
  stacks weight onto an already-gated call (avoids review→deny over-escalation).
- The harness is honest: it found a real regex bug (`dd if=...`) on the first run.
