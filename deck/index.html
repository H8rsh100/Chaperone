Aegis-Swarm

Follows provenance across agents, isolates the one that is tainted, and gates the action itself. Fail-closed. Recorded.

Inside the kernel: four layers, one decision
rules µs→ embeddings MiniLM 384-d→ LLM judge off hot-path→ provenance sentinel taint→ policy allow / review / deny→ execution allowlist→ hash-chained ledger

Deterministic first. A real model second, fully offline. A sentinel that tracks where the data came from. Human in the loop for ambiguity. A hard allowlist as the backstop.

Aegis-Swarm: the layer above the kernel

Follow the data, not just the command.

planner trusted→ retriever untrusted fetch→ taint graph lineage→ saliency MiniLM, offline→ isolation carry ≥ 0.5→ Chaperone kernel fail-closed→ Ed25519 ledger

Aegis sees the context boundary. Chaperone sees the action. The kernel blocks the call; Aegis freezes the one agent that carried it. A human confirms containment, and the swarm resumes on a sanitized context — or stays isolated.
